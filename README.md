A [make.fun](https://make.fun/bounty/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2) bounty entry: one line, at most 120 characters, in which a robot vacuum explains why it missed a spot. A judge model reads the lines two at a time and picks the funnier excuse each time; the funniest line takes the $2 reward.

## The entry

> That crumb survived 3 cleans and 2 firmware updates, so I left it there. I salute it and move on.

97 characters. A machine making peace with failure: exact numbers (3 cleans, 2 firmware updates), an explicit excuse, and a salute to a crumb that earned its place.

## Run it

```sh
python3 main.py            # writes /output/entry.txt
python3 main.py --self-test
```

`main.py` writes the entry, reads it back, and verifies it byte-identically against the pick. The self-test checks the competition gate (UTF-8, 1–120 characters, one line, no padding) plus the drafting rules: 15 distinct candidates, the pick inside the 62–140 byte winning size band, a concrete machine marker, and none of the field's saturated tropes.
